# まだ つかって いない 絵の 置き場

ここに ある ものは **納品ずみ だけれど、いまは アプリで つかって いない** 絵です。
消しては いません。つかう ことに なったら 1つずつ `public/art/` に もどします。

## bg/ — ミニゲームの 背景 59まい(Codex 6回目・2026-07-30 納品)

### なぜ つかって いないか

入れて みて、実際の 画面で 見くらべた 結果です。

1. **そもそも 効くのは 7ゲームだけ**だった
   背景は `ui/scenery.ts` が 描く 背景を 置きかえる しくみ。ところが
   おまつり 47本と 収穫の 5本(reap / rhythm / sweep / scoop / shell)は
   それぞれが 自前で 背景を 描いて いる ので、絵は うしろに かくれる。
2. **`mine`(ねんど掘り)は 見た目が 変わらない**
   ほるタイルが 画面を ほぼ 覆う ため。絵ありと 絵なしで 同じ 画に なった。
3. **のこり 6つは 後退に 見えた**
   いまの コード描画は 「空の グラデーション + 丘 2まい + 太陽 + ゆっくり
   流れる 雲」。納品の 背景は 平たい 色の 帯 2〜3本。
   うめ(catch)では、落ちてくる 実が 横切る ところに こい緑の 帯が 来て、
   みどりの 実が 見にくく なる 向きでも あった。

「今の ほうが よければ 今の ままで いい」という 方けつ(2026-07-30)に そって、
1まいも 採用しないで 置いて おく ことに した。

### つかいたく なったら

1. つかいたい ゲームの 1まいを `public/art/bg/` に コピーする
   (例: `cp art-hold/bg/bg-yosakoi.svg public/art/bg/`)
2. それだけで 出る。コードは さわらない(`src/ui/bgArt.ts` が 拾う)
3. 出ない ときは 名まえの ずれ。`src/core/bgName.ts` の 対応表を 見る
   (おせわ=care は bg-defense、ふつうの おまつり=yatai は bg-festival)

### つかえる ように する には(絵の 作り直しが 要る)

いまの コード描画より よく する なら、背景の ほうに
「空の グラデーション・遠くの もの・光」くらいの 作りこみが 要る。
発注文(docs/CODEX_ART_PROMPT.md の 背景の 回)に
「平たい 色の 帯だけに しない。ただし あそぶ ものより 目立たせない」を
足して たのみ直すのが よい。
