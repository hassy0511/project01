## 決定事項(人間の承認済み)

### 道具

- **道具は各地の本物の工芸でクラフトする**(自動入手ではない)。道具そのものが名産の勉強になる
- 動詞(収穫エンジン)ごとに1本、全10種。作る県は実在の工芸産地に合わせる(裏取り前は trivia に check)
- レベル: Lv1=最初から持っている ふつうの道具(暗黙) / Lv2=工芸の県でクラフト /
  Lv3=Lv2を20回使い込むとレシピが目覚め、しんの めいさん級の素材で作る(P2で実装)
- **効果はアーケード補助のみ**: 判定幅・かごの大きさ等を エンジンごとに1係数。**上限15〜20%(テストで固定)**。
  Lv3は加えて おまけドロップ(+1こ、確率、上限あり)
- 実装形: 時間制のエンジンは「あそび時間 ×(1+係数)」。**時間なし盤面制の mine は
  「シャベル +1本(Lv2)/+2本(Lv3)」に読み替える**(2026-08-04 の mine 盤面制化に伴う)
- **やらないこと**: 成長時間の短縮(原則4「待ち時間は他県への動機」と衝突)/購入・通貨/
  ★1保証やレシピ必要数への干渉。**道具なしでも全コンテンツ完成可能**(既存テストが保証)
- 道具の素材として てつ・たけ・き を新設(産地は複数県。進行順テストを通ること)

### しんの めいさん(第2章)

- 名称は「**しんの めいさん**」(ずかんは金枠)。県のおまつりを開くと解放
- ミニゲームが格段に難しい(難しさ係数をデータで指定)+育つ時間30〜60分級
  - 時間制のエンジン: あそび時間 ×0.85 + ★しきい値 ×1.6
  - 時間なし盤面制の mine: シャベル -1本 + ★しきい値 ×1.6(2026-08-04〜)
- 県ごとに そざい+2〜3・レシピ+2。**まず かんとう7県で試作**→子供の反応→全国展開
- トリビアは check 付きで先に入れ、裏取りは後追い(既存方針)

### 季節

- **ゲーム内の季節。2週間ごとに はる→なつ→あき→ふゆ**(8週間で一年)。
  実カレンダー連動は「ずかんコンプに最長1年」となるため不採用
- 季節は端末時刻から決める固定関数(起点日からの経過週÷2 mod 4)。セーブに依存しない
- **季節限定は激レアのみ**: 実際に旬が強い名産だけに season を付ける
  (例: まつたけ=あき、さくらんぼ=なつ、ゆきしたにんじん=ふゆ)
- 季節外れは「〜に なったら とれるよ」と案内。枯れ・没収は無し(原則3)

## スキーマ追加(相談済み)

- `RecipeType` に `'dougu'`
- `Recipe.tool?: { engine: HarvestEngine; level: 2 | 3 }` — 作ると `save.tools[engine] = level`
- `Material.shin?: true` / `Material.season?: 'haru'|'natsu'|'aki'|'fuyu'` / 難しさ係数(P2)
- セーブに `tools: Record<engine, level>` と `toolUse: Record<engine, count>`(追記なので互換)

1. **P1 道具の土台**(この計画の主対象): スキーマ+素材3種+道具レシピ10本+補助フック+もちもの表示
2. **P2 しんの めいさん かんとう試作**: 季節の時計・金枠ずかん・難しさ係数・Lv3道具

4. **P4 ちゅうもん**: 実装済み。晴れた県に注文スロット1つ(core/orders.ts)。
   たのまれる物=その県で入手不能かつ開拓済みの県で入手可能(どうぐ・しん・季節限定・おまつりは除外)。
   締めきり・失敗なし。とどけると 県ごとの かざり(初回。GameData.kazari 47件)+通算数で称号(orderTitles)。
   ずかんに「おれい」タブ。しんの全国展開は かんとうの手応えを見てから

## バランスの検証方法

- 補助係数の上限をデータ整合性テストで縛る
- 既存E2E自動プレイで「道具なし/道具あり」の★分布を機械計測(ノー操作★1保証は不変であること)
