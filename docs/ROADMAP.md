### 固まり(フリーズ)対策 ── 2026-07 実機で見つかった罠

実機(iPad・子供のプレイ)で「キャベツをど真ん中に入れると止まる」「落ちものの金の実で止まる」が発生。
原因は演出の**ヒットストップ**で、Phaser のシーン操作の性質を踏み外していた。

- `scene.scene.pause()` / `resume()` は**その場では効かない**。SceneManager のキューに積まれ、次フレームで適用される
- いっぽう `isPaused()` / `isActive()` は**いまの状態**を返す
- 旧 `hitStop` は「pause → 70ms 後に `isPaused()` なら resume」だった。
  次フレームが 70ms より遅れる(=重いフレーム=大きな演出を出したその瞬間)と
  resume を取りこぼし、そのあと pause だけが効いて**シーンが二度と動かない**
- 止まったシーンは update も回らないので、自力では立ち直れない

**規約**: 演出のために `scene.scene.pause()` を使わない。一瞬止めたいときは
`tweens.timeScale` / `time.timeScale` を 0 にして、実時間で必ず戻す(`src/ui/effects.ts` の `hitStop` 参照)。
`isPaused()` の結果を使って resume するかどうかを決めるコードを書かない。

さらに、原因不明の固まりからも立ち直れるように `src/game/watchdog.ts` を常駐させている
(止まったままのシーンを起こす / コマが進まなければ読みこみ直す)。回帰は `e2e/verify-freeze.mjs`。
