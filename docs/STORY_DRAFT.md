# 以下は検討時の原案(記録)

「なんで開拓するんだっけ?」に答える最小限の物語を用意し、子供の入り込みを作る。
方針: **作り込みすぎない**。ゲームループは既に成立しているので、ストーリーは
「動機づけの一言」と「節目の演出」に徹する。テキストはぜんぶ ひらがな分かち書き。

---

## 案A: 「もやもやぐもと ちいさな かいたくだん」(推し)

### あらすじ
ある あさ、にっぽんじゅうが ふしぎな「もやもやぐも」に つつまれた。
くもの したでは、まちの めいさんも おまつりも、みんなの きおくから
きえかけている。たんけんヒヨコの ぴっけは、さいごの「かいたくだんいん」
として きみを スカウト。けんを ひとつずつ かいたくし、そざいを そだて、
めいさんを よみがえらせ、おまつりの あかりで くもを ふきとばす たびに でる。

### なぜこの案か
- **既存の演出と完全に整合する**: 未開拓県には既に雲がかかっており、開拓で晴れる。
  おまつり開催で🏮が灯る。「くもをはらう たび」という物語は、いま画面で起きている
  ことの意味づけを後付けできる(=実装コスト最小)
- 開拓の動機(くもを はらう)、育成の動機(めいさんを よみがえらせる)、
  祭りの動機(あかりで まちを げんきにする)が1本の線でつながる
- 「记憶が消えかけている」→ものしりカード(トリビア)が「おもいだしたきろく」になる。
  図鑑を埋める行為が物語の目的そのものになる

### ゲーム内での見せ方(実装するときの粒度)
1. **はじめてのきどう**: 3〜4枚の紙芝居(静止画+1行テキスト+タップ送り)。
   ぴっけ登場 → もやもやぐも → 「きみが かいたくだんちょう だ!」
2. **県かいたく成功時**: 現在の成功モーダルに1行たす
   (「くもが はれて ○○けんの みんなが おもいだしたよ!」)
3. **おまつり開催時**: フィナーレ花火のあとに1行
   (「おまつりの あかりで まちが ぴかぴかに もどった!」)
4. **エリアコンプ時(関東全県で🏮)**: ちょっと豪華な紙芝居+つぎのエリアへの引き
5. ぴっけの地図ガイド(既存)の口調をこの世界観に寄せる

### 実装コスト見積り
- 紙芝居シーン(汎用 StoryScene: 画像/絵文字+テキスト+タップ送り): 小
- 各節目の一言追加: 極小(uiText 追記のみ)
- 絵素材: 最初は絵文字+ベクター描画で成立。M4 アート統一時に差し替え

## 案B: 「ずかんはかせと かぜの いたずら」

### あらすじ
ものしりはかせ(ぴっけの おじいちゃん)が だいじにしていた
「にっぽん めいさんずかん」が、おおかぜで バラバラに とんでいって しまった!
ページは にほんじゅうの けんに ちらばっている。けんを たずね、めいさんを
じぶんの てで つくりなおすと、ずかんの ページが もどってくる。

### 長所・短所
- ○ 図鑑埋め(ゲームの実態)と物語が直結。子供に「ページを取り戻す」は分かりやすい
- ○ はかせという相談役キャラが増え、トリビア読み上げ役を任せられる
- △ 「雲」の既存演出との結びつきが弱い(雲の説明を別に用意する必要がある)
- △ キャラを1体追加でデザインする必要(ぴっけだけで回す案Aより重い)

## 案C: 「みんなの おねがい きいて!」(注文システム連動型)

### あらすじ
各けんの じゅうにん(どうぶつたち)が「○○が たべたいな」「おまつりが
みたいな」と おねがいしてくる。おねがいを かなえるたびに まちが にぎやかに
なっていく、ごほうびは じゅうにんからの「ありがとう カード」。

### 長所・短所
- ○ ROADMAP P3 の「注文システム」構想とそのまま合流できる(毎セッションの目的が生まれる)
- ○ 住人キャラで県の個性(方言・名物)を出せる
- △ 注文システム実装が前提になり、コストが3案で最大
- △ 「壮大な目的」がなく、たんたんと続く構造(小さい子には十分だが、6〜12歳の
  上の層には あっさりしすぎるかも)

## 推しと進め方

**案Aを推す。** 理由: いまの画面演出(雲・🏮・図鑑)に物語を後付けできて実装が最小、
かつ「くもを はらって にっぽんを ぜんぶ はらす」という 47県スケールの長期目標が
そのまま エリア解放(にほんぜんこく画面)の動機になる。
案Cの「住人のおねがい」は、案Aの世界の中の日常クエストとして後から共存できる
(くもが はれた けんの住人が おねがいしてくる、という順序)。

### 次の一歩(合流時にやること)
1. この案で行くか、味付けの方向(コミカル寄り/しっとり寄り)を決める
2. ぴっけの口調・一人称を確定(現状ガイド文言のトーン=げんきな ですます抜き)
3. StoryScene(紙芝居)の骨組みを実装し、はじめてのきどう1本だけ流す
4. 節目テキスト(開拓成功・祭り開催・エリアコンプ)を uiText に追記
5. 名称候補もこの世界観で再検討(例: 「めいさんクエスト」→「にっぽん かいたくだん(仮)」等)

### 決めてほしいこと(宿題)
- [ ] 案A / B / C どれで進めるか(組み合わせ可)
- [ ] 導入紙芝居の長さ(3枚か5枚か。スキップボタンは必須で付ける)
- [ ] 「きおくが きえかける」という表現が怖すぎないか(マイルドにするなら
      「くもの したは みんな ねむたくなって おまつりを わすれちゃう」等)

# 第2章: ストーリー強化(2026-07-28 起案)

## 課題(ユーザーfeedback)

1. 導入(もやもやぐも)は分かるが、そのあと物語が消えて「たんたんとゲームをやる」だけになる
2. 県が晴れた瞬間に「やったぜ」がない(祭りスコアモーダルの1行だけ)
3. キャラが弱い(ぴっけは吹き出し係、はかせは導入で消える、雲は敵として何もしない)
4. 完全クリア(47県)しても何も起きない。やり込みへの引き継ぎもない

## 方針

**新しい仕組みは作らない。いま画面で起きている状態変化に「物語の意味」と「キャラの反応」を貼る。**
トーンはコミカル寄り(もやもやは怖い敵ではなく、まぬけで にくめない いたずら者)。
テキストはすべて uiText 集約・ひらがな分かち書き。健全設計(失敗ペナルティなし)は不変。

## キャラの役割分担(これが背骨)

| キャラ | 役割 | 出る場所 | 口調 |
|---|---|---|---|
| **ぴっけ**(ヒヨコ) | 冒険の相棒。いっしょに喜ぶ・急かす | 地図・県ページ・祭り | 「〜だ!」「いこう!」元気 |
| **ものしりはかせ**(フクロウ) | 記録係・知識係。ずかんとトリビアの主 | ものしりカード・ずかん・節目の授与式 | 「〜じゃ」「ほっほう」 |
| **もやもや**(雲) | コミカルな敵。祭りの音が苦手 | 地図の未開拓県・吹き飛ぶ演出 | セリフなし(「うわ〜!」の悲鳴だけ) |

- ものしりカードの読み手を ぴっけ → **はかせ** に交代(owl の mood 差分を追加)
- ぴっけの mood に **cheer(ばんざい)** を追加(晴れ演出・コンプ用)

## ビート設計(時系列)

### B1. 県が晴れる瞬間(最重要・初回のみ)
祭り初成功 → 地図に戻った直後、**地図上でシネマ**:
1. カメラがその県へ寄る
2. もやもや(顔つき雲)が「う わ 〜」と回転しながら吹き飛ぶ(風すじ+SFX)
3. 県に色がつき、🏮がぽんと立つ。住人アイコン2〜3人が跳ねる
4. ぴっけ(cheer)「はれた〜! ○○けんの みんなが おまつりを おもいだした!」
5. はれメーター(下記)が +1 される
実装: `state.flags['hare:<prefId>']` 未セットなら再生。2回目以降の祭りは今まで通り(やり込みの邪魔をしない)。

### B2. エリア開放(くもの すきまが ひらく)
条件達成で新エリアが開く瞬間、RegionScene で 1枚だけの短い紙芝居:
雲のすきまから新エリアのシルエットが見える+ぴっけ「つぎは ○○だ! いってみよう!」
実装: `flags['regionOpen:<id>']`。データは regions への追記(1行のセリフ)。

### B3. エリアコンプ(全県🏮)= はかせの授与式
はかせが登場して「ちほうバッジ」を授与(モーダル+紙吹雪+ファンファーレ)。
バッジは RegionScene のエリア名の横に常時表示(進捗の勲章化)。
「ほっほう、かんとうの そらは もう まっさお じゃ!」

### B4. エンディング(47県ぜんぶ晴れ)
最後の県が晴れた B1 の直後に接続して 3枚の紙芝居:
1. 日本地図から雲がぜんぶ吹き飛ぶ(逆・導入)
2. 全国に🏮の明かり。ぴっけ+はかせ並ぶ「きみは でんせつの かいたくだんちょう じゃ!」
3. **やり込みへの引き継ぎ**: はかせ「まだ ずかんに あいた ページが あるのう…」
   → ずかん・★3・さいこうスコアが「クリア後の物語」だと明示する
以後、RegionScene の空が晴れ渡り(常時快晴の背景+ときどき花火)、タイトルに金の勲章。
設定に「おもいでを 見る」(導入・エンディングの再生)を追加。

### B5. 真コンプ(ずかん100%)
はかせ「わしの ずかんを こえたのう…きょうから きみが ものしりはかせ じゃ!」
称号だけの小さなご褒美(モーダル1枚)。過剰に作り込まない。

### 常時: にっぽん はれメーター
RegionScene 上部に「はれた けん ○/47」の太陽ゲージ。
長期目標を1本の線で見せる(いま region ごとの数字しかない)。

## 実装ステージ(それぞれ独立にテスト可能)

| 段 | 内容 | 規模 |
|---|---|---|
| 段1 | B1 県はれシネマ + はれメーター + flags | 中 |
| 段2 | キャラ分担(はかせ=トリビア/ずかん、owl/chick mood追加、もやもや吹き飛び共通部品) | 小 |
| 段3 | B2 エリア開放ビート + B3 バッジ授与式 | 中 |
| 段4 | B4 エンディング + おもいで再生 + クリア後の空 + B5 真コンプ | 中 |
| 段5 | E2E(hare シネマ/エンディングの admin 直行)+全回帰 | 小 |

state 変更はすべて既存の `flags: Record<string, boolean>` への追記(スキーマ変更なし)。
セリフ・バッジ定義は data/uiText.ts と data/gameData.ts regions への追記(スキーマ追記のみ)。
