# アプリ名の検討(2026-07)

ストア提出前に「(仮)」を外す。判断はハッシーさん。以下は調査と提案。

## 調査結果

- **「めいさんクエスト」「名産クエスト」で既存アプリ・登録商標は見つからなかった**
  (App Store / Google Play / web 検索)
- 既存の都道府県学習アプリ(競合)の名前: 「あそんでまなべる 日本地図クイズ」
  「すいすい都道府県クイズ」「日本地名パズル」→ いずれも名称の衝突なし
- **「〜クエスト」は要注意**: スクウェア・エニックスが「ドラゴンクエスト」を
  9類(電子機器)・28類(ゲーム)・41類(娯楽・教育)で広く登録。
  「〜クエスト」型の名称は世の中に多数あり(まちクエスト 等)、
  使用自体が直ちに侵害になるものではないが、**商標登録を目指す場合は
  類似指摘のリスクがある**(弁理士に相談する価値あり)
- ストア審査では「他社の権利を侵害する名称」が却下理由になりうる。
  登録しない場合でも、紛らわしくない名前のほうが安全

## 候補

| 候補 | よいところ | 気になるところ |
|---|---|---|
| **めいさんクエスト**(現行) | すでに愛着がある。内容がそのまま伝わる | 「クエスト」の商標リスク(登録は難しい可能性) |
| **めいさんずかん** | 図鑑=このゲームの核。商標リスクが小さい | 「ずかん」は説明的で、商標としては弱い(=誰でも使える) |
| **にっぽん めいさんの たび** | 旅=開拓と移動の感じが出る。衝突しにくい | すこし長い |
| **めいさんめぐり** | 短い・語感がよい・衝突しにくい | ゲーム感がやや弱い |
| **もやもや雲と めいさんの島** | 物語(もやもや雲)が名前に入る。独自性が高い | 長い。ストアの表示で切れる |

## おすすめ

**「めいさんめぐり」**(サブタイトル「にっぽん かいたく!」を併記)
— 短くて子供が言いやすく、商標リスクが小さく、内容も伝わる。
どうしても「クエスト」を残したい場合は **「めいさんクエスト」のまま出す**(登録はしない)
という選択も現実的。
