# アプリ名(2026-07-29 確定)

## 正式名称

**はれはれクエスト 〜にっぽん めいさん たんけん〜**

- 通称・アイコン下の表示・ゲーム内ヘッダー: **はれはれクエスト**
- ストアの表示名: 上記のフルネーム(副題が検索キーワードを背負う)

## なぜこの名前か

- **子供が声に出せる**。「はれはれ」の繰り返しは幼児語のリズムで、4歳でも言える
- **繰り返しが遊びの構造そのもの**。1県ずつ 47回 晴らしていくゲームで、
  名前がその動作を音で表している
- **タイトルが目標を言っている**。もやもや雲を晴らす → 47県ぜんぶ晴れる、という
  ストーリーと完全に一致する(docs/STORY_DRAFT.md 第2章)
- **副題が親向けの検索語を背負う**。「めいさん」「にっぽん」「たんけん」で
  日本地理の学習ゲームだと分かる。本題は子供向け、副題は親向け、と役割を分けた

## 調査(2026-07-29 / Web検索ベース)

- 「はれはれクエスト」「ハレハレクエスト」の**完全一致は App Store / Google Play /
  Web ともに見つからなかった**
- 隣接するもの(衝突ではないが把握しておく):
  - **ハレ晴レユカイ**(涼宮ハルヒの憂鬱 ED・2006年)。「ハレハレ」の音は
    30〜40代に一定の想起がある。商標区分も分野も別で、問題はない
  - **HARE(ハレ)**(アダストリアのアパレル)。区分が違うため衝突しない
- 却下した候補と理由:
  - **おまつりクエスト** → タイトーの「おまつりクエスト ヒッパレQ」が実在
  - **にっぽんクエスト** → 一般的すぎて既存が多いと見られる
  - **はれるん** → 気象庁の公式マスコット名
  - **めいさんクエスト**(旧・仮称) → 「めいさん」を4歳は知らず、声に出しにくい

## 調査アップデート(2026-08-06 / Web検索ベースの再確認)

- 「はれはれクエスト」「ハレハレクエスト」の**完全一致は引き続き見つからない**
  (App Store / Google Play / Web)
- 商標DB系サイト(patent-i.com 等)の索引にも「ハレハレ」の文字商標は見当たらない。
  近い既登録: **ハロハロ**(ミニストップ)・**ハレノヒ / HARENOHI** — いずれも称呼が異なる
- J-PlatPat 本体への自動アクセスは不可(bot遮断・SPA)のため、
  **最終確認は下の手順で人間が行う必要がある**(5分で終わる)

## J-PlatPat 確認手順(手動・約5分)

1. <https://www.j-platpat.inpit.go.jp/> → 上部メニュー「商標」→「商標検索」
2. 検索項目を**「称呼(単純文字列検索)」**にして `ハレハレ` で検索(称呼はカタカナで入れる)
3. 同様に `ハレバレ`(「晴れ晴れ」の読み違い側)と `ハレハレクエスト` でも検索
4. ヒットした場合は各件の**「区分」**を見る。問題になり得るのは
   **第9類(ダウンロード可能なプログラム/電子出版物)**と
   **第41類(娯楽・教育・オンラインゲームの提供)**に重なるものだけ。
   それ以外の区分(食品・アパレル等)は衝突しない
5. 9類・41類に重なるヒットがあったら、類似かどうかの判断は素人でやらず**弁理士に相談**
6. 商標を**出願する**場合も弁理士経由が確実(9類+41類の2区分。
   費用の目安: 特許庁印紙代+代理人費用で2区分あわせて10〜15万円程度)

検索結果のスクリーンショットを残しておくと、あとで docs に貼れて記録になる。

## 名前を変えたときに触る場所(この改名で実際に触ったファイル)

- `src/data/uiText.ts` — `TITLE_TEXT` / 設定画面のバージョン表記 / プライバシー本文
- `src/data/gameData.ts` — `meta.title` / `meta.subtitle`
- `index.html` — `<title>` と `apple-mobile-web-app-title`
- `public/manifest.webmanifest` — `name` / `short_name`
- `public/privacy.html` — タイトルと見出しと本文
- `CLAUDE.md` / `docs/*.md` の見出し

## 触ってはいけない場所

**localStorage のキーは名前を変えても そのまま**にする。

- `meisanquest-save-v1`(セーブ本体)
- `meisanquest-mute` / `meisanquest-mute-story`
- `meisanquest-watchdog-reloads`

キーを変えると**すでに遊んでいる子のデータが消える**。ユーザーから見えない内部名なので、
旧名のままにしておく。将来どうしても変えるなら「旧キーから読んで新キーに移す」処理が要る。

npm のパッケージ名(`meisan-quest`)とリポジトリ名(`project01`)も同じ理由で据え置き。
